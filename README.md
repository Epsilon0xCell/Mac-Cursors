## How to use a cape

1. Install Mousecape from its project page: https://github.com/alexzielenski/Mousecape
2. Download the `.cape` file you want from the `capes/` folder in this repo.
3. Open the file with Mousecape, or import it from inside the app, so it appears in your cape library.
4. Apply the cape from Mousecape. To go back, apply a different cape or restore the default cursor in Mousecape.

## Honest limits

- A cape only changes how the cursor looks. It does not change cursor behavior, speed, or anything outside Mousecape.
- These are collected cape files, shared as data files. Whether a given cape renders as its author intended depends on your macOS version and your Mousecape version; if one misbehaves, remove it in Mousecape and pick another.
- This repo does not include Mousecape itself. The app lives at its own project page, linked above.
